Category Grid is a quiz-show grid: categories across the top and clues worth more as you go down. A team picks a clue, everyone buzzes in, and a right answer scores the clue's value and gets the next pick. Points go straight onto the normal scoreboard.

## How do I set up a grid?

Choose **Category Grid** under **Game** when you create a game, and tick **Start with the sample grid** to begin from a filled-in holiday trivia grid. The host desk then opens on the **Category Grid** tab. You can also set one up later in any game from that tab (owners and co-hosts only).

1. Give the grid a title and type a title for each category.
2. Select a tile to edit its **clue** (what everyone sees), its **answer**, any wordings you'll **also accept**, and private **host notes**.
3. Set each row's value in the **Value** column. Use **Add category** (up to 8) and **Add row** (up to 10) to change the size. Every category has the same number of clues.
4. Choose the rules: whether **a wrong answer locks the team out of that clue** (on by default), and whether **wrong answers lose the clue's value**.
5. **Save grid**. Anything under **Fix before starting** must be fixed first.
6. When everyone has joined, **Start Category Grid**. The clues are locked from then on.

**Import or export** shows the grid as text in the question bank format, so you can keep a backup or reuse it in another game. Clues are text only for now: images, audio and video aren't supported yet.

Keep your answers private: clues stay hidden until opened, and answers until shown. Only owners and co-hosts see them early.

## Running the grid

1. The team named under **Picks next** chooses a clue. Tap it on the grid to show it on every screen. If **Also update the buzzer** is ticked, the buzzer starts a fresh question so every team can buzz.
2. Read the clue, then select **Open buzzer**.
3. Whoever holds the buzz is chosen for you under **Who answered?** (or choose them). Press **Correct** or **Wrong**.
   - **Correct** adds the clue's value, shows the answer, and gives that team the next pick.
   - **Wrong** locks the team out of this clue (if that rule is on) and takes off the clue's value (if that rule is on). The buzzer lets the next team answer.
4. If nobody gets it, press **Nobody got it: show the answer**. The pick stays with the same team.
5. **Back to the grid** marks the tile as played.

Use **Picks next** to give the pick to someone else at any time, or choose **Nobody (host picks)**. **Finish grid** ends the game with the final scores.

Players see the grid and the open clue above their buzzer, and the audience display shows them in large type.

## How do I fix a mistake?

- **Undo last action** takes back the last step and its points. Two things stay as they are, because everyone has seen them:
  - A clue that was shown can't be played again (undoing **opening** it marks the tile as void).
  - An answer that was shown stays on screen, so you can judge again.
- **Void this clue** is for a clue that went wrong, for example a mistake in the question. It takes back every point that clue gave or took, gives the pick back, and marks the tile as void.

You can also change scores by hand on the **Play** tab. The scoreboard's **Undo score** only reaches changes made since the grid last changed the scores, so it can never take points away from the grid. Use **Undo last action** for those.

## How do I go back to the buzzer?

**Use basic controls** stops the grid for good in this room. Players, teams, chat and scores stay.

- **The buzzer closes.** Open it when you're ready.
- **Players and the display** are told the game carries on with the buzzer.
- **The scoreboard's Undo score** only reaches changes made after this point. To play the grid again, duplicate the game: the copy keeps the clues and rules.

A game runs one game mode at a time. To switch a game from Ranked Answers to Category Grid (or back) before it starts, use **Discard setup** on the mode you don't want.
